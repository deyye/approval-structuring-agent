# 字段和证据口径 v2

单位比较保留原值，只对标准化值计算。日期按真实年月日排序。同项目以唯一代码归组，不凭同名自动合并；代码缺失时独立列示，人工确认后才能合并。阶段以批文标题为依据，文件名只显示，不决定归类。

|---|---|---|
| 发文机关标志 | 首页红头完整文字 | 不从正文落款补齐 |
| 发文字号 | 首页独立的当前批复文号 | 不取正文请示及引用文号 |

## 动态指标

先从建设内容章节识别指标，再补充设计专篇中的面积/层高等数字属性。每条保留 `name`、原文值、标准化数值、范围上界、限定词、单位、证据及 `scope`（construction/design）。

- 面积、长度、体积、投资额、时间、速度、电力与数量单位分维度计算。
- “约”“不超过”“不少于”“以上”“以下”均保留；范围上下界不丢失。
- 1公里与1000.0米在同口径下等价；1平方米与1米不可比较。
- 建筑占地面积、总建筑面积、地上建筑面积分别列示。
- 道路路面面积与行车道/路缘带/硬路肩面积保持独立，不擅自合并。
- DN管径型号、道路桩号、标准编号、年份不作为数量指标。
- 同一指标多值时全部保留并提示冲突，允许逐条人工复核。

## 状态

`extracted` 已提取；`missing` 原文未载明；`uncertain` 页面不可读、无法证明缺失；`needs_review` 角色推断或视觉候选；`conflict` 同文多值；`reviewed` 人工已复核。

每个证据保存文本行 ID、页码、PDF bbox 和引文。人工可重新选择原文行，修订记录保存原值、原证据、新值、说明和时间。`revision` 阻止旧页面覆盖新修订。手工修订属于人的确认，并非大模型自动真实性证明。

## 评测边界

公开的`evaluation/gold.json`仅包含虚构演示材料的独立预期值，不包含用户真实批文。真实材料标注通过评测脚本的`--gold`指定本地私有路径，预测与原文不进Git。页码命中不等于像素级坐标准确率；候选印章不等于自动验真。不得把演示集或开发样例成绩解释为业务泛化准确率。
