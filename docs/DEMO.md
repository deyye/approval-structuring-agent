# 5分钟验收演示

## 无需原始材料的一键演示

按 README 创建环境并安装依赖，然后运行：

```bash
python scripts/demo.py --serve
```

生成两个**明确标注为虚构**的项目、各三个阶段 PDF，调用实际解析流程导入后启动工作台。不会加载预填提取结果。已有文件按内容哈希去重。

## 使用这六份真实样例

```bash
python scripts/demo.py --samples /path/to/six-pdfs --serve
```

也可以先 `python -m app.server`，在网页点击上传，一次选择六份 PDF。

## 演示顺序

1. 查看左栏：两个虚构项目，各3份批复、3个阶段。
2. 基本信息表：展示14项字段，点击文号可查看原文。
3. 建设指标表：查看不同阶段的面积变动及颜色。
4. 点击面积值：检查PDF页码、原文片段及黄色高亮。
5. 选择“单文档”：检查该批复字段，确认审批阶段。
6. 修订字段，选择来源行，填写理由并保存；观察比对变化和修订历史。演练后恢复原值。
7. 切换项目：检查归组正确、字段不串项目。
8. 下载Excel，检查各项目对照、单文档明细、证据和历史。
9. 重启服务：确认结果仍保留。配置模型后可重新提取，并保留人工修订。

使用真实材料时，原始文件与标注仅保存在自己的私有目录。公开仓库不包含真实材料或其派生结果。
